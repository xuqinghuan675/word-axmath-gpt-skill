# 高中数学资料排版工作流

适用于整理、重排高中数学讲义、练习册和题目文档。当前任务中用户提出的具体要求优先；按实际来源和用户指定范围处理，不补造原稿没有的题目、章节或配图事实。

## 工作流程

1. 核对原稿及范围，辨认单元、小节、例题、课后练习和各题配图、图注；保留题目内容、小问、选项、公式和各类题目内部的原有顺序。先在副本上工作，不覆盖原稿；缺少所要求的小节或内容时核实来源，不凭空补齐。文件名未体现章节时，在授权范围内继续检查相关 PDF 的后续页面及正文；扫描件可逐页渲染、识别，并用题目及配图与讲义交叉核对，确认章节边界。无法找到原稿时，按用户允许的范围处理并说明未核实的部分。
2. 按单元和小节分组，各单元及小节分别从新的一页开始，小节标题居中；单元标题紧接首个小节时，两者可同在该新页顶部。小节内先排“例题”，再排“课后练习”；仅有一类时只整理原稿中存在的部分。
3. 每小节的例题从 1 开始依次编号，课后练习再从 1 开始另行编号；下一小节重复这一规则。不要把多个小节合并成一串题号，也不要改动题内小问、选项的含义。原文可能将各小节例题集中排列、再集中排列练习；对照原稿确认每组边界后再归组，记录原题与新位置的对应关系，核查题目和公式没有丢失或串题。图注若引用题号，核实其对应关系；独立图号按原稿保留。
4. 带图题按“题目 → 对应图片 → 图号或图注”连续排列：图片位于完整题目及小问的正下方，图号或图注居中并紧接图片正下方，不移到其他题目旁边。原有图注保留并核对题号；没有题图标签而配图归属明确时，按题号补“第 N 题图”，例题可沿用“例题 N 图”等原文既有格式。多个分图可共享一个明确对应本题的图注；原稿中有独立图号时保留，涉及编号变化时同步核对正文引用。题干中的数表等内容按原意保留在需要的位置，不强行移至题末。
5. 将表达数学意义的公式和单个字母变量使用可编辑的公式编辑器表示，核对原式含义；普通正文中的非数学字母无需强行转换。若将 Word OfficeMath/OMML 转为 AxMath，使用本仓库 [SKILL.md](../SKILL.md) 指定的生产工具和验收流程。已有 AxMath 对象须保持真实可编辑，不能用图片冒充公式。需要转换时，可先完成结构和公式准备，再将排版工作稿作为转换输入；同时对照原始资料核实内容、编号和配图。转换后重新检查实际版面；若需要再调整，按该技能重新进行相关诊断和最终验收。
6. 题目之间留出供书写的空白：同类题的空间大致一致，多问或复杂题（尤其三问）留更多空间。每页第一题靠页面正文区顶部；该页有单元或小节标题时，标题置顶、第一题接在标题和必要分组标签之后。每页一般最多 3–4 题，含大题时一般安排 2–3 题；按题目大小及答题空间调整，较长题可单独占页，不为凑题数压缩留白。每页末题后须留有书写空间；前题留白过多时，可先用普通空段落重新平衡本页空间，仍不足再把末题整题移到下一页。通过调整空白，使同一道题的题干、小问、配图和图注保持在同一页。若题目本身无法完整放入一页，明确指出实际情况，不伪称通过。
7. 分页和留白只通过普通回车形成的空段落调整；每小节另起一页也按此方式完成。不靠题首或题间堆叠的 Shift+Enter 软换行制造空白；发现原有此类留白时，在副本中改用普通空段落，内容本身需要的换行应按原意保留。不插入人工分页符，也不更改段前分页、与下段同页、段中不分页、孤行控制等段落分页/保持选项，包括 `pageBreakBefore`、`keepWithNext`、`keepLines`、`widowControl`。保留原稿的分节和既有分页/保持设置；若现有设置妨碍实现本次要求，说明实际冲突并请用户决定处理方式。内容改动可能影响后续页面，调整后重新检查受影响的页面。

## 交付前检查

- 根据原稿核对单元、小节、题目和配图，确认没有漏题或编造内容；检查各单元、小节另起一页、小节标题居中，例题和课后练习分别从 1 编号。
- 实际渲染并查看最终文档的每一页，检查页首可见题文或标题是否顶到正文区顶部、各页题量、末题下方留白、题目是否跨页、同类题答题空间，以及图片和居中图注是否紧接对应题目；多问大题尤其检查末题后的实际书写空间。段落标记的位置不能代替可见内容位置：题首软换行、高公式和内嵌图可能使文字或图片实际位置偏移。发现公式与文字重叠时，在保留原公式和内容的前提下调整普通段落，并重新查看；核查公式和单字母变量的可编辑性及数学含义。
- 按题目映射核对正文、公式和配图，必要时比较公式对象与图片的数量、引用及内容哈希；对象数量或哈希一致仅说明对象得以保留，不能单独证明公式显示和数学含义正确。若本次未逐一转换普通文本中的数学字母，应如实说明，不能把保留已有公式当成全部转换完成。
- 检查排版范围内的段落分页/保持设置及人工分页符，确认未新增分页符或改动这些选项。对于 AxMath 转换，另外执行 [SKILL.md](../SKILL.md) 规定的完整检查和逐页验收；普通排版不必凭空启动公式转换。
