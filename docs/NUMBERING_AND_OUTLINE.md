# 数学资料编号与标题层级（唯一权威规范）

本文件是数学讲义、练习册、试卷及题目 Word 文档中编号和标题结构的唯一规则来源。只排版、不转换公式的任务同样执行。

## 1. 两项独立问题

**编号对齐**与**标题折叠**必须分别检查：

- 编号：题号是否为正文手打文字；同级编号是否对齐；编号后的正文和续行是否对齐。
- 折叠：段落是否仍使用 Word 内置 Heading 样式或有效大纲级别；WPS/Word 是否仍显示展开/收缩箭头。

## 2. 首轮生成时的固定规则

### A. 先查清源稿真实编号状态

开始生成前，逐类确认：

- 题号是否已经是段落中的手打文字，还是 Word 显示出来的自动编号；读取 Word 实际显示编号（如 ListString），不能只看 XML 中的可见文本。
- 检查段落和样式继承链中的 w:numPr、w:numId、w:ilvl，以及 numbering.xml 中的列表定义。
- 检查 w:instrText / 字段代码中是否存在 LISTNUM、SEQ、AUTONUM 等编号域。
- 检查段落 w:pStyle、样式继承链和有效 w:outlineLvl，确认题目段落是否带有 Heading 身份或折叠层级。
- **不能只根据段落缩进判断编号状态**；编号结构和标题折叠是两项独立检查。

### B. 编号直接生成普通文字

1. 从冻结来源读取原编号，直接写入段落文字，例如 1.、(1)、（1）；保留原序号、标点、跳号和层级。
2. 题目段落使用普通正文或自定义普通样式；禁止 Word 自动编号、多级列表、样式继承编号、编号域和内置 Heading 折叠身份。
3. 同级编号统一左缩进、悬挂缩进；在编号后设置统一制表位，正文和续行都从该制表位对齐。仅统一段落缩进不算完成。
4. 保留不同层级原有的视觉缩进差异；不得把所有层级压成同一级，也不得用连续空格凑位置。
5. 标点按冻结来源或用户本次明确要求处理；编号、正文标点和公式内容分别处理，不使用跨对象全局替换。
6. 先完成包含不同编号层级的代表页，在 Word/WPS 检查编号起点、正文起点、续行位置和折叠箭头；通过后再按同一规则生成全文。


## 3. 已有 DOCX 的处理顺序

### A. 自动编号先物化为普通文字

1. 在真实 Word 中读取目标段落实际显示的编号，例如 `Paragraph.Range.ListFormat.ListString`。
2. 优先调用 `ListFormat.ConvertNumbersToText`，确认编号已进入正文且只出现一次。
3. 若不能可靠转换，先读取 `ListString`，把准确编号写入段落文字，再解除列表格式。不能先 RemoveNumbers 或先改 Normal 样式，否则显示编号可能消失。
4. 对题号字段先读取显示结果，再用 `Field.Unlink` 保留当前文字、解除字段。页码和脚注等非题号字段不处理。
5. 只处理目标题号段落，不删除整个 `numbering.xml`。

### B. 清除 Heading 样式身份和折叠层级

**只把 `w:outlineLvl` 设为 `9` 不够。** WPS 可能仍按内置 Heading 样式身份显示折叠箭头。

1. 确定目标段落的 `w:pStyle`，以及 `styles.xml` 中对应的样式 ID、显示名称、`basedOn`、`next`、`link` 和有效大纲级别。
2. 将目标 Heading 样式克隆为自定义普通样式，例如 `PlainTextStyle1`、`PlainTextStyle2`；新样式的 `w:styleId` 和 `w:name` 均使用不含 Heading / 标题 1–9 的普通名称。
3. 保留原样式的字体、字号、粗体、颜色、段前段后、行距、缩进和制表位。把继承链中需要的格式复制到新样式或目标段落，再让新样式基于 `Normal` 或普通正文样式，切断 Heading 大纲身份。
4. 同步更新目标段落的 `w:pStyle`；检查新样式的 `basedOn`、`next`、`link`，不得再指向内置 Heading。需要保留链接时克隆对应字符样式并更新双向引用，不需要时移除无用链接。
5. 只改目标段落和它们使用的样式，不全局改写仍被其他正常标题使用的内置 Heading 样式。
6. 新样式大纲级别设为正文（`w:outlineLvl=9`）或移除大纲级别；同时清除目标段落及新样式继承链中的自动编号定义。

## 4. 文件保护

- 原稿不覆盖；先复制并冻结 SHA-256，在新 DOCX 上处理。
- 优先只修改 `word/document.xml` 和 `word/styles.xml`；除非确有必要，不触碰关系文件、OLE、嵌入对象、图片和媒体。
- 核对 AxMath OLE 对象、关系 ID、嵌入文件和媒体保持原样，题目正文与公式内容保持原样。
- 不要只隐藏折叠箭头，也不要把不同层级的缩进全部压成同一级。

## 5. 检查与验收

1. 运行只读检查：`python scripts/inspect_question_numbering.py "<docx>"`。它会定位自动列表、样式继承编号、题号字段、Heading 样式身份及 `basedOn/next/link` 关系，不会修改文档。
2. 结构检查确认：题号是普通文字；目标段落及样式链没有活动 `w:numPr` 或题号字段；目标段落不再引用内置 Heading 1–9；新样式的 `basedOn/next/link` 不会重新引入 Heading；没有有效大纲级别；同级编号、正文和续行对齐，跨层级保留原缩进差异。
3. 必须实际打开 Word 和 WPS 验收：标题左侧没有展开/收缩箭头，编号对齐正确。只看 XML 或只把 outlineLvl 改为 9 不算界面验收。
4. 若无法打开其中一个应用，只报告已实际打开的应用和结构检查结果；没有界面证据，不得声称该应用的折叠箭头已解决。

## 6. 工具边界

- `inspect_question_numbering.py`：只读定位，不负责修复。
- `normalize_numbering_punctuation.py`：只改普通文字标点，不会物化自动编号，也不处理样式身份和折叠。
- `--numbering-scope preserve`：只保留题号文字标点，不会移除自动编号、Heading 样式或折叠层级。
